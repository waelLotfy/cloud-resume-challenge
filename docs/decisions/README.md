# Architecture Decision Records (ADRs)

This directory records significant architecture decisions for the Cloud
Resume Challenge project, using the lightweight ADR format popularized by
Michael Nygard.

## Index

| ID | Title | Status |
|----|-------|--------|
| [0001](./0001-record-architecture-decisions.md) | Record architecture decisions | Proposed |

## Creating a New ADR

1. Copy [`0001-record-architecture-decisions.md`](./0001-record-architecture-decisions.md)
   as a template.
2. Name the new file `NNNN-short-title.md`, incrementing `NNNN`.
3. Add a row to the index table above.
4. Reference any related requirement IDs (`FRn`/`NFRn`) and GitHub Issues.
